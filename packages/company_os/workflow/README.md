# Phase 4 finite runtime

`runtime.py` executes synthetic jobs through shared application commands. PostgreSQL
owns claims, leases, fencing, retries, waits and recovery. The worker reserves one
safety process and four ordinary processes and rotates authorized workspaces.
Fake effects only; no generic BPM, real providers, AI or Phase 5 approval engine.
See `docs/phases/phase-4-brief.md` and the independent-review handoff.
